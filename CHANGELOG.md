# Changelog

## 0.1.0 - 2026-11-05

First numbered version. The licence is MIT.

This slice lends one local git checkout and puts it back on release. A queue is honoured. A missing home pin keeps the holder. A dirty checkout is refused. A plain status does not print the observed commit. A line break in a name or reason is refused. One settings file names one host. An uncertain borrow names the lease, including when the last record write fails after the checkout and the read-back have succeeded. `pinlease --version` prints 0.1.0. A missing rules file on that flag is a refusal: exit 2, the message, and no traceback.
